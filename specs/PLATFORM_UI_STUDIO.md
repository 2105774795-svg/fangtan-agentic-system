# Research Studio 工作台 UI 优化

本轮依据用户提供的参考图重新组织工作台，保留首页及浮雕底图擦除动效，不接入真实 AI 或改变后台业务流程。

## 主要变化

- 移除画布上方的大标题与重复阶段栏，顶栏下方直接展开画布。
- 顶栏集中品牌、项目切换、保存状态、导出与面板折叠。
- 以项目为中心展开六个阶段，分类使用低饱和色彩与曲线连线。节点直接关联已保存的成果；规划项与真实文件分开显示，不显示虚构资料数量。
- 新增画布缩放比例、适应全部节点、定位当前阶段、缩略图切换。
- 右侧改为调研对话、资料、任务、见解四个页签。资料来自实际成果，任务对应现有阶段，见解页只展示已确认方向和材料现状。
- 对话采用用户气泡、助手标记、可折叠执行记录、后续操作与底部输入框。支持引用已有成果名称；录音入口明确为未接入。
- 桌面助手可拖动改变宽度，也可通过分隔条的方向键调整；宽度偏好保存在浏览器。
- 保留原有需求选择、保存、刷新恢复、成果编辑、版本历史、下载与未保存保护。
- 适配手机抽屉、深色模式和减少动态效果。

代码拆分到 Workspace.tsx、ResearchMap.tsx、AssistantPanel.tsx 与 ArtifactEditor.tsx；工作台样式独立放在 workspace.css。

## 验证范围

TypeScript 与生产构建，以及 scripts/test-platform.cjs 浏览器回归。新增验证包括中心节点及六分支、四页签、资料数量、缩放与缩略图、助手宽度键盘调整、取消离开保留编辑稿、成果引用、深色工作台与手机无横向溢出。使用独立临时数据库，不修改日常项目。

新界面仍是示例流程；真实模型回复、外部检索、现场录音、多人协作、分享权限均未在本轮接入。界面没有添加虚构协作者或假报告。
