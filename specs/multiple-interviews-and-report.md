# 多场访谈与整合报告

采集页顶部提供“新建访谈”和项目内访谈列表。每场可以填写对象或场次名称，拥有独立的 session ID、录音、提纲选择、逐字稿与纪要。重复提交同一创建请求不会创建重复场次；选择历史场次会持久化当前选择。

## 暂停、中断和结束

- `sessions.status=live` 表示本场未结束。`recording_state` 区分待开始、正在录音和已暂停。
- 暂停会停止麦克风、保留本机分片并记录暂停状态，返回后可以继续同一场。
- 若重新打开页面发现服务端仍标记正在录音，而当前页面没有活动录音器，显示“录音已中断，可继续”；不自动结束访谈。
- “结束本场访谈”先解释其与暂停的区别，确认后才能调用 finish，转为 `done/ended`，合并录音并生成纪要。结束后的场次不可再录；补充采访使用新场次。
- 原始分片约每十秒保存。意外关闭时可恢复已持久化分片，浏览器尚未交付的最后不足十秒音频不保证保存；不把这部分伪装为完整记录。

现有 sessions 表采用增量加列，保留历史录音和关联。历史录音时长优先从已有逐字稿时间点回填；无可靠时长时显示待确认，不按墙钟计算录音时间。

## 同步和汇总

每场原始材料以 source_session 关联；重复同步更新已有材料版本，不重复计数。已结束且有逐字稿但尚未同步的场次会阻止分析或报告任务，并提示到采集页同步。可以批量同步这些场次。新增原文使已有分析与报告标记待更新。

报告任务接收各场真实状态、名称、场次编号、材料编号及逐段引用；每份原始材料都必须被引用。场次、分片、材料份数与独立受访人数分别说明，同一对象的补访不得简单累计为独立人数。未结束或无原文的访谈只说明状态，不生成内容。

## 报告格式与导出

市场调研与企业访谈采用用户提供的整合报告结构：封面说明、执行摘要、研究范围与判读方法、对象现状与需求归纳、需求整合清单、逐场访谈与实地记录、待补数据、关键分歧与风险、材料索引。只继承结构与编排，不引入参考项目的具体事实或照片。口述史继续采用人生章节结构。

报告支持 Markdown 编辑及 Word 导出。Word 使用 A4、宋体正文、黑体分级标题、封面、目录、页码、可编辑表格及跨页重复表头。导出只使用已保存内容；待更新报告须先重新分析或生成。报告页提供“重新生成汇总报告”，历史成果保留。

本轮只更新本地版本，不部署服务器。验证覆盖后端状态、两场独立证据、未同步拦截、引用完整性、浏览器录音恢复、Word 下载及实际 Word 渲染。
